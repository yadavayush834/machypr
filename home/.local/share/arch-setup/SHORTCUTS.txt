macOS-style Arch desktop

Super is the keyboard logo key (shown as Command in the menu).

Super+Return: Terminal
Super+E: Finder-style file manager
Super+Space: Spotlight application search
Super+R: Launchpad application grid
Super+M: Minimize window
Super+Ctrl+F: Toggle full screen
Super+Tab: Window switcher
Super+W: Close window
Super+L: Lock
Super+V: Clipboard
Print: Screenshot
Super+Alt+W: Wallpaper
Super+Alt+B: Control menu
Super+Alt+N: Wi-Fi
Super+Alt+D: Show or hide dock
Super+1-9: Switch desktop
Super+Shift+1-9: Move window to desktop
Super+left drag: Move window
Super+right drag: Resize window
Super+Shift+Space: Toggle floating
